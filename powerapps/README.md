# วางหน้าจอแอป `CEO-APP` ด้วยโค้ด (เร็วกว่าสร้างเองตามคู่มือ ค / ซ)

ไฟล์ใน [`screens/`](screens/) คือโค้ดหน้าจอแบบเดียวกับที่ Power Apps Studio ให้ตอนคลิกหน้าจอแล้ว Ctrl+C ได้หน้าตาตามภาพออกแบบ (Artifact "CEO-APP หน้าของ CEO") ครบทุก Control ตำแหน่ง สี และสูตร

| ไฟล์ | หน้า | ของใคร |
|---|---|---|
| `scrHome.yaml` | ภาพรวม (ใหม่) | พนักงาน |
| `scrTickets.yaml` | งานจาก CEO (จัดใหม่ ปุ่มรีเฟรชล่าง + แถบล่าง) | พนักงาน |
| `scrDetail.yaml` | รายละเอียดงาน (จัดเป็นการ์ด) | พนักงาน |
| `scrCeoHome.yaml` | ภาพรวม | CEO |
| `scrCeoTickets.yaml` | งานทั้งหมด | CEO |
| `scrCeoDetail.yaml` | รายละเอียดและตรวจงาน | CEO |
| `scrCeoCreate.yaml` | สั่งงาน | CEO |

ใช้เวลาประมาณ 30–45 นาที

## ก่อนวาง (ทำครั้งเดียว ประมาณ 15 นาที)
1. **บันทึกจุดย้อนกลับ:** ในแอป กด **Save** (ถ้าวางแล้วพัง ย้อนได้ที่ make.powerapps.com → Apps → `CEO-APP` → **⋯** → **Details** → **Versions** → **Restore** เวอร์ชันก่อนหน้า)
2. **คอลัมน์ใน SharePoint ต้องมีครบ** (คู่มือ ก ข้อ 7.1): `Tickets` → `CEOExtra`, `GroupID` · `Employees` → `IsManager`
3. **แหล่งข้อมูลในแอป:** แถบ **Data** → `Tickets` → **⋯** → **Refresh** (ให้แอปเห็นคอลัมน์ใหม่) · **Add data** → SharePoint → `CEO-Tickets` → ติ๊ก `Employees`
4. **App → Formulas** เพิ่มต่อท้าย (ใส่อีเมลจริงแทน `<...>` ตัวพิมพ์เล็ก)
   ```powerfx
   ceoEmails = ["<อีเมล CEO>", "<อีเมลผู้พัฒนา>"];
   isCEO = Lower(User().Email) in ceoEmails;
   ```
5. **Flow `OnLineEvent`:** ทำคู่มือ ซ ส่วนที่ 1 (เปลี่ยน Trigger condition) เพื่อให้งานที่ CEO สั่งหรือตอบจากแอปแจ้งพนักงานได้

## วาง
**รอบที่ 1: หน้า CEO 4 หน้า (ไม่ชนกับของเดิม จึงลองได้ก่อนโดยไม่ต้องลบอะไร)**
1. เปิด `scrCeoDetail.yaml` ด้วย Notepad → **Ctrl+A** → **Ctrl+C**
2. ใน Power Apps คลิกพื้นที่ว่างในแผง **Tree view** → **Ctrl+V** → ต้องมีหน้า `scrCeoDetail` โผล่ขึ้นมา
   - หน้านี้ใช้กล่องจัดเรียงอัตโนมัติ (`GroupContainer`) ถ้าวางผ่าน แปลว่าทุกไฟล์วางได้
   - ถ้าขึ้น Error ให้หยุด แล้วดูตาราง "ถ้าวางไม่ได้" ด้านล่าง (ยังไม่ได้ลบอะไร แอปเดิมใช้ได้ตามปกติ)
3. วางต่อ: `scrCeoHome` → `scrCeoTickets` → `scrCeoCreate`

**รอบที่ 2: หน้าพนักงาน**
1. วาง `scrHome` (หน้าใหม่ ไม่ชนกับของเดิม)
2. **ลบหน้าเดิม 2 หน้า** `scrTickets` และ `scrDetail` (คลิก **⋯** → **Delete**) เพราะชื่อ Control ในแอปห้ามซ้ำกัน ถ้าไม่ลบ หน้าที่วางจะได้ชื่อต่อท้าย `_1` และสูตรจะชี้ผิดที่
   - ระหว่างนี้จะมี ✖ ที่ StartScreen หรือสูตรอื่นที่อ้างหน้าเดิม ไม่เป็นไร หายเองหลังวางครบ
3. วาง `scrTickets` แล้ว `scrDetail`

**รอบที่ 3: ตั้งค่าท้าย**
1. **App → StartScreen**
   ```powerfx
   If(!IsBlank(Param("ticketId")), scrDetail, isCEO, scrCeoHome, scrHome)
   ```
2. ลากหน้าใน Tree view ให้ `scrHome` อยู่บนสุด (ไม่บังคับ)
3. **Save** แล้วเปิด **App checker** (ไอคอนหูฟังแพทย์) ถ้ามี ✖ ส่งภาพมา

## วางทับหน้าที่เคยวางแล้ว (เมื่อไฟล์ใน `screens/` มีรุ่นใหม่)
ชื่อ Control ห้ามซ้ำกันทั้งแอป จึงต้องลบหน้าเดิมก่อนวางทุกครั้ง
1. **Save** ก่อน (เป็นจุดย้อนกลับ)
2. ลบหน้าที่จะวางใหม่ (**⋯** → **Delete**) ทีละหน้า แล้ววางไฟล์ของหน้านั้นทันที ระหว่างนี้ ✖ ที่ `Navigate(...)` ของหน้าอื่นหายเองเมื่อวางครบ
3. ถ้าได้ชื่อ `_1` ต่อท้าย แปลว่ายังมีหน้าเดิมหรือ Control ชื่อซ้ำค้างอยู่ ลบหน้า `_1` แล้วหาตัวที่ซ้ำ

**หน้าภาพรวมใน Studio ตัวเลขว่าง เป็นปกติ** เพราะตัวเลขคำนวณตอนเปิดหน้า (OnVisible) ซึ่ง Studio ไม่รันตอนแก้ไข ให้กด ▷ Preview ที่หน้านั้นหนึ่งครั้ง ปิด Preview แล้วตัวเลขจะค้างให้เห็นใน Studio

รายการทุกหน้าอยู่ในกล่อง (`conTodo`, `conTickets`, `conCPeople`, `conCAll` …) ถ้าจะย้ายหรือปรับขนาด ให้ปรับที่กล่อง ไม่ใช่ที่แกลเลอรีข้างใน (ค่า X ของแกลเลอรีหายตอนวาง)

ไฟล์ YAML คือแบบล่าสุดที่ตรงกับภาพออกแบบ ชื่อ Control บางตัวต่างจากคู่มือ ค / ซ ที่สร้างด้วยมือ (เช่นปุ่มย้อนกลับเป็น `btnBack` / `btnCBack`, การ์ดตัวเลขมี Label ซ้อน `lblKLateT/N/S`) ถ้าแก้ตามคู่มือแล้วหาชื่อไม่เจอ ให้ดูชื่อใน Tree view

## ถ้าวางไม่ได้
| อาการ | ทำอย่างไร |
|---|---|
| Ctrl+V แล้วไม่มีอะไรเกิดขึ้น | คลิกในแผง Tree view ก่อนแล้วลองใหม่ · ถ้ายังไม่ได้ ใช้วิธีทำตามคู่มือ ค ข้อ 2.4.5–2.4.6 และคู่มือ ซ แทน |
| Error ที่ `GroupContainer` หรือบอกว่าไม่รู้จัก Control | หน้า `scrDetail` / `scrCeoDetail` ใช้กล่องจัดเรียงอัตโนมัติ ให้ Insert → **Vertical container** ในหน้าว่าง → คลิกกล่อง → Ctrl+C → วางใน Notepad แล้วส่งบรรทัด `Control:` มาให้ผม จะแก้รุ่นให้ตรง |
| หน้าใหม่ชื่อ `scrDetail_1` | ยังไม่ได้ลบหน้าเดิม ลบหน้า `_1` ทิ้ง ลบหน้าเดิม แล้ววางใหม่ |
| ✖ ที่ `CEOExtra`, `GroupID`, `IsManager` | ยังไม่ได้เพิ่มคอลัมน์ หรือยังไม่ได้ Refresh แหล่งข้อมูล (ก่อนวาง ข้อ 2–3) |
| ✖ ที่ `isCEO` | ยังไม่ได้ทำ App → Formulas (ก่อนวาง ข้อ 4) |
| ทักทายเป็นชื่อจริงภาษาอังกฤษ ไม่ใช่ชื่อเล่น | อีเมลใน `Employees` ไม่ตรงกับอีเมลที่ login (ตัวพิมพ์เล็กใหญ่ต้องตรงกัน) หรือยังไม่ได้เพิ่ม `Employees` ในแอป |
| ไอคอนแถบล่างขึ้น ✖ (`Icon.DetailList`) | คลิกไอคอนนั้น → Icon เลือกรูปรายการอื่นจากเมนู |
| หน้า CEO รายคนขึ้น "ไม่พบในรายชื่อพนักงาน" | ticket นั้นสั่งให้อีเมลที่ไม่มี (หรือ `Active` = No) ใน `Employees` มักเป็นงานทดสอบ |

## ทดสอบหลังวาง
ใช้ตารางทดสอบในคู่มือ ค (หน้าพนักงาน) และคู่มือ ซ ข้อ H1–H9 (หน้า CEO)
- หน้า CEO เลื่อนวันส่งด้วยปุ่ม **พรุ่งนี้ / ศุกร์นี้ / +7 วัน** (ไม่มีปฏิทินเลือกวัน เพื่อไม่ต้องพึ่ง Control ที่ยังไม่รู้รุ่น)
- หน้าสั่งงานของ CEO เลือกคนด้วยการแตะชื่อ (แตะซ้ำเพื่อเอาออก) หรือแตะ **หัวหน้าทุกคน**

## แก้หน้าจอในอนาคต
แก้ที่ `tools/staff_screens.py` หรือ `tools/ceo_screens.py` แล้วรัน `python3 staff_screens.py ../screens` และ `python3 ceo_screens.py ../screens` ในโฟลเดอร์ `tools/` จะได้ไฟล์ YAML ใหม่ (รุ่นของ Control อ้างจากโค้ดที่ export จากแอปจริงวันที่ 26 ต.ค. 2026)
