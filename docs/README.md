# CEO-APP — ระบบสั่งงานและติดตามงานของ CEO

เอกสารออกแบบสำหรับแอปที่ CEO ใช้สั่งงานพนักงานรายคน ติดตามความคืบหน้า และดูปฏิทินส่วนตัว
สร้างบน Microsoft 365 ที่บริษัทมีอยู่แล้ว (Power Apps + SharePoint List + Power Automate)

> สถานะ: **ร่างออกแบบ** ยังไม่ได้ทดสอบกับ Tenant จริง หัวข้อที่มี ⚠️ ต้องยืนยันในขั้นต้นแบบ ([00-prototype.md](00-prototype.md))
> ไฟล์เดิมใน Repo นี้ (`index.html`, `README_TH.md`, `WORKSHEET_TH.md`, `hiro-marker.png`) เป็นแบบฝึก AR ไม่เกี่ยวกับโปรเจกต์นี้ และยังไม่ได้ถูกแตะต้อง

## ข้อตัดสินใจที่ตกลงกันแล้ว
1. **ผู้ใช้หลัก:** CEO (คุณสมชาย ประจักษ์สูตร์) สั่งงานและติดตามงาน พนักงานราว 80 คนรับงานและอัปเดต
2. **ขอบเขตเฟสแรก:** ระบบ Ticket ของ CEO + ปฏิทินส่วนตัวของ CEO เท่านั้น ข้อมูล SAP B1, Pipeline, KPI, Forecast ไว้เฟสหลัง
3. **แพลตฟอร์ม:** Power Apps (Canvas) ติดตั้งผ่านแอป Power Apps แล้วตั้งทางลัดบนหน้าจอโฮม (ไม่ทำแอปที่มีไอคอนของตัวเอง ไม่ผ่าน App Store / Google Play)
4. **ที่เก็บข้อมูล:** SharePoint List ใน Site แยกเฉพาะแอปนี้ **ไม่ใช้ Dataverse** (ที่ Tenant ปัจจุบันเป็น Trial จะหมดอายุ)
5. **License:** ใช้เฉพาะ Connector ระดับมาตรฐานที่ Microsoft 365 Business Standard รองรับ ห้ามใช้ Connector แบบ Premium
6. **Ticket:** ผู้รับผิดชอบ 1 คนต่อ 1 ใบ สถานะ ใหม่ → รับทราบ → กำลังทำ → รอ CEO → เสร็จ แล้ว CEO ปิดงานเอง ("รอ CEO" = พนักงานรอคำตอบจาก CEO, "เสร็จ" = รอ CEO ตรวจ — ยืนยันแล้ว)
7. **ปฏิทิน:** อ่านและสร้างนัดในปฏิทิน M365 ของ CEO ด้วยสิทธิ์ของ CEO เอง นัดส่วนตัวตั้งเป็น Private วันกำหนดส่งของ Ticket แสดงเฉพาะในแอป ไม่เขียนลงปฏิทิน M365
8. **ความลับ:** Ticket ทุกใบถือเป็นความลับ เห็นได้เฉพาะ CEO กับผู้รับผิดชอบของใบนั้น สิทธิ์ตั้งโดย Flow จุดเดียว ปรับกฎได้ตามคำสั่ง CEO
9. **ผู้พัฒนาและดูแล:** เจ้าของโปรเจกต์ (คนเดียว) จึงต้องมีผู้ดูแลสำรองและเอกสารส่งต่อ

10. **กลุ่มทดลอง:** CEO, PM, การตลาด, Presales, Sales และคุณ Suchada 1 สัปดาห์ CEO สั่งงานผ่านแอปเท่านั้น
11. **คู่แข่งตัวจริงคือ LINE:** หน้าสร้างงานต้องเร็วพอ ๆ กับพิมพ์ LINE (เกณฑ์ไม่เกิน 15 วินาที)

12. **CEO สั่งงานผ่าน LINE (ขั้น 1B) ทำทันที:** CEO สั่งงานด้วยเสียง > Forward > รูป > พิมพ์ จึงให้ LINE Official Account ของบริษัท + n8n รับคำสั่ง ถอดเสียง แยกผู้รับผิดชอบ/งาน/กำหนดส่ง แล้ว**ให้ CEO กดยืนยันใน LINE ก่อนสร้าง Ticket ทุกครั้ง** Power Apps ใช้สำหรับพนักงานอัปเดตงานและ CEO ดูภาพรวม ส่วนหน้าสร้างงานใน Power Apps เป็นช่องทางสำรองเมื่อบอทล่ม
13. **ที่รัน n8n:** ระหว่างพัฒนาและทดลองใช้โน้ตบุ๊กของผู้พัฒนา (Cloudflare Tunnel, ห้าม Sleep, เปิด BitLocker) ก่อนใช้งานจริงย้ายไป **n8n Cloud**
14. บอทต้องตอบรับใน LINE ทันทีทุกครั้ง เพื่อให้ CEO รู้ทันทีถ้าระบบล่ม (ไม่เงียบหาย)
15. **บัญชี LINE:** เปิด **LINE Official Account ใหม่แยกเฉพาะงานสั่งงาน** (ไม่ใช้ OA การตลาด) ใช้ Messaging API ตั้งค่าให้ค้นหาไม่ได้ และบอทตอบเฉพาะ LINE user ID ของ CEO CEO ใช้งานเหมือนแชตกับเพื่อน: กดค้างไมค์แล้วพูด, Forward หรือส่งรูป ห้ามใช้บัญชี LINE ส่วนตัวกับระบบอัตโนมัติ (ผิดเงื่อนไข LINE)
16. **วิธีพูดสั่งงาน:** CEO กด**ไมค์บนแป้นพิมพ์**ในแชต LINE ให้มือถือแปลงเสียงเป็นข้อความ ตรวจแล้วกดส่ง ถ้าส่งข้อความเสียงของ LINE มา บอทตอบให้ใช้ไมค์บนแป้นพิมพ์แทน
17. **ไม่ใช้ AI ในเฟสแรก:** บอทใช้ข้อความที่ CEO ส่งเป็นชื่องาน แล้วให้ CEO **แตะปุ่มเลือกผู้รับผิดชอบและวันส่ง** (พูด 1 ครั้ง + แตะ 2 ครั้ง) ไม่มีค่า AI ไม่ส่งข้อความลับไปผู้ให้บริการเพิ่ม และแทบไม่มีโอกาสสั่งผิดคน เพิ่ม AI ภายหลังได้โดยไม่ต้องรื้อระบบ รายละเอียดใน [06-line-bot.md](06-line-bot.md)
19. **n8n → SharePoint:** App Registration `DF-CEO-Bot-n8n` สิทธิ์ `Sites.Selected` เขียนได้เฉพาะ Site `CEO-Tickets` Global Admin ทำให้ครั้งเดียว ขั้นตอนใน [06-line-bot.md](06-line-bot.md)
18. **รายชื่อพนักงาน:** SharePoint List `Employees` (ชื่อจริง นามสกุล ชื่อเล่น ชื่อเรียกอื่น อีเมล แผนก สถานะทำงาน) **HR เป็นเจ้าของและอัปเดต** ถ้าใช้สร้างปุ่มเลือกผู้รับผิดชอบและค้นหาด้วยชื่อเล่น

## เรื่องที่ยังเปิดอยู่
- ⚠️ ความเร็วแจ้งเตือนพนักงานเมื่อ Ticket มาจากบอท LINE (Flow ตั้งสิทธิ์และแจ้งเตือนจากตัวกระตุ้น "When an item is created" อาจหน่วง ต้องวัดจริง)
- ⚠️ ผู้มีสิทธิ์ Global Admin / SharePoint Admin ของ Tenant (ผู้ใช้ปัจจุบันมีสิทธิ์ Exchange Admin และ User Admin เท่านั้น) ใช้สร้าง SharePoint Site และปลด/ตรวจนโยบายการสร้างแอป
- ตัดสินใจเรื่องบัญชีบริการ (Service account) สำหรับเป็นเจ้าของ Flow ดู [05-handover.md](05-handover.md)
- ลบ Trial ที่ไม่ใช้ออกจากบัญชี (Power Apps Plan 2 Trial, Power Pages vTrial, Copilot Studio Viral Trial, Copilot for Finance Trial)
