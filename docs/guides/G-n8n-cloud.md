# คู่มือ ช: ย้ายบอท LINE ขึ้น n8n Cloud (Starter)

ใช้เวลาประมาณ 45 นาที · ทำครั้งเดียว · หลังย้ายแล้วปิดโน้ตบุ๊กและ PowerShell ได้เลย URL ของบอทจะไม่เปลี่ยนอีก

ทำไมต้องย้าย
- บนโน้ตบุ๊ก ถ้าปิดเครื่อง ปิด PowerShell หรือเครื่อง Sleep บอทจะเงียบทันที
- URL ของ Cloudflare quick tunnel เปลี่ยนทุกครั้งที่เปิดใหม่ จึงต้องแก้ Webhook ใน LINE และ SharePoint ทุกครั้ง
- n8n Cloud เปิดตลอด 24 ชม. และ URL คงที่: `https://<ชื่อ>.app.n8n.cloud`

ค่าลับเก็บที่ไหน
- แพ็กเกจ Starter ไม่มีเมนู Variables จึงเก็บค่าลับ 8 ค่าใน**โหนด `Settings`** ของ Workflow
- โหนดนี้ไม่ต่อกับโหนดใด และไม่เคยถูกรัน ส่วน Code node อ่านค่าจากโหนดนี้โดยตรง
- ถ้าอัปเกรดเป็น Pro ภายหลัง ย้ายค่าไปที่ **Variables** ได้เลย (โค้ดอ่าน Variables ก่อน) แล้วล้างค่าในโหนด Settings ทิ้ง

> ⚠️ **กฎของโหนด Settings**
> - ใครเปิด Workflow นี้ใน n8n ได้ จะเห็นค่าลับทั้งหมด ให้มีผู้ใช้ n8n แค่ผู้พัฒนาและคุณ Suchada
> - **ห้าม Export, Download, Duplicate ไปที่อื่น หรือแชร์ Workflow นี้** เพราะค่าลับจะติดไปกับไฟล์
> - ห้ามส่งค่าลับทางแชต อีเมล หรือ LINE ให้คัดลอกจากไฟล์ `.env` บนโน้ตบุ๊กแล้ววางในโหนด Settings โดยตรง
> - ถ้าสงสัยว่าค่ารั่ว ให้ออกค่าใหม่ทันที: LINE Channel secret / Access token (LINE Developers), `MS_CLIENT_SECRET` (Global Admin)

## 1. สมัคร n8n Cloud (10 นาที)
1. เปิด https://n8n.io → **Get started** → สมัคร **ด้วยอีเมลบริษัท** ห้ามใช้อีเมลส่วนตัว เพื่อให้คุณ Suchada ดูแลต่อได้
2. ตั้งชื่อ Instance เช่น `dgf-ceo` จะได้ URL `https://dgf-ceo.app.n8n.cloud` ⚠️ **เปลี่ยนชื่อภายหลังไม่ได้** และ URL นี้จะอยู่ใน LINE และ SharePoint
3. ช่วง Trial 14 วันยังไม่ต้องใส่บัตร (ถ้าหน้าสมัครขอบัตร ให้ใช้บัตรบริษัท)
4. **เปิด 2FA:** รูปโปรไฟล์มุมล่างซ้าย → **Settings** → **Personal** → **Enable 2FA** แล้วสแกนด้วยแอป Authenticator
5. **ตั้งเขตเวลา:** เปิด **Admin panel** (https://app.n8n.cloud) → Instance ของเรา → **Manage** → Timezone = **Asia/Bangkok** (Workflow ตั้ง Asia/Bangkok ไว้แล้ว ข้อนี้กันพลาดอีกชั้น)

## 2. นำบอทเข้า (10 นาที)
1. ดาวน์โหลดไฟล์ [`n8n/ceo-line-bot.json`](../../n8n/ceo-line-bot.json) (ไฟล์เต็มที่มีโหนด Settings ว่าง ๆ ไม่มีค่าลับ)
2. ใน n8n Cloud: **Create workflow** → เมนู **…** มุมขวาบน → **Import from File…** → เลือกไฟล์
3. ต้องเห็นกล่องสีเหลือง **"⚠️ Settings มีค่าลับ"** และโหนด **Settings** ลอยอยู่ด้านบน (ไม่ต่อกับอะไร ถูกต้องแล้ว)
4. ดับเบิลคลิกโหนด **Settings** แล้วกรอกช่อง Value ทีละแถว โดยคัดลอกจากไฟล์ `.env` บนโน้ตบุ๊ก (`C:\n8n-ceo\.env` หรือที่เก็บไว้)

   | Name | ใส่ค่า |
   |---|---|
   | `LINE_CHANNEL_SECRET` | จาก `.env` |
   | `LINE_CHANNEL_ACCESS_TOKEN` | จาก `.env` |
   | `MS_TENANT_ID` | จาก `.env` |
   | `MS_CLIENT_ID` | จาก `.env` |
   | `MS_CLIENT_SECRET` | จาก `.env` |
   | `SP_HOSTNAME` | กรอกให้แล้ว `digitalfocusth.sharepoint.com` |
   | `SP_SITE_PATH` | กรอกให้แล้ว `/sites/CEO-Tickets` |
   | `SP_WEBHOOK_CLIENT_STATE` | จาก `.env` |

   - ช่อง Value ต้องเป็น **Fixed** (ตัวอักษรธรรมดา) ห้ามกดเป็น **Expression** และห้ามมีช่องว่างหรือเครื่องหมาย `"` ติดมา
   - **ห้ามแก้ช่อง Name** (ต้องตรงทุกตัวอักษร)
5. ปิดหน้าต่างโหนด → ตั้งชื่อ Workflow เป็น `CEO LINE Bot`
6. เมนู **…** → **Settings** ของ Workflow ตรวจว่า Timezone = Asia/Bangkok และ **Save successful production executions** = **Do not save**
7. กด **Publish** มุมขวาบน

## 3. ชี้ LINE มาที่ Cloud (5 นาที)
1. ใน n8n Cloud ดับเบิลคลิกโหนด **LINE Webhook** → แท็บ **Production URL** → คัดลอก ต้องได้ `https://<ชื่อ>.app.n8n.cloud/webhook/ceo-line-bot`
2. https://developers.line.biz → Provider → Channel ของ OA สั่งงาน → **Messaging API** → **Webhook URL** → **Edit** → วาง → **Update** → **Verify** ต้องขึ้น **Success**
3. ตรวจว่า **Use webhook** เปิดอยู่
4. ทดสอบ: CEO (หรือผู้พัฒนาในโหมดทดสอบ) ส่ง `สรุป` ใน LINE ต้องได้คำตอบภายใน 10 วินาที
5. ถ้าไม่ตอบ: n8n Cloud → **Executions**
   - ไม่มี Execution ใหม่ = URL ใน LINE ผิด หรือยังไม่ได้ Publish
   - Error `ไม่พบค่าตั้ง LINE_...` = ช่องในโหนด Settings ว่างหรือชื่อผิด
   - ผล `bad-signature` = `LINE_CHANNEL_SECRET` ผิด (มีช่องว่างติดมา)
   - Error `401/403` จาก Microsoft = `MS_*` ผิด

## 4. ชี้ SharePoint webhook มาที่ Cloud (5 นาที)
ทำหลังข้อ 2 (Publish แล้ว) เพราะ SharePoint จะเรียก URL ยืนยันทันที
1. เปิด `https://digitalfocusth.sharepoint.com/sites/CEO-Tickets` ด้วยบัญชี Owner → **F12** → แท็บ **Console**
2. วางเนื้อหาไฟล์ [`setup/create-webhook.js`](../../setup/create-webhook.js) → Enter
3. URL: `https://<ชื่อ>.app.n8n.cloud/webhook/ceo-sp-hook` · clientState: ค่า `SP_WEBHOOK_CLIENT_STATE` เดียวกับในโหนด Settings
4. ต้องเห็น `สร้าง webhook ... หมดอายุ ...` และ `เสร็จแล้ว`
5. webhook ของโน้ตบุ๊ก (URL `trycloudflare.com` เดิม) จะหมดอายุเองหรือ SharePoint จะเลิกเรียกเมื่อเรียกไม่ติด ไม่ต้องลบ
6. **จดวันหมดอายุ** (179 วัน) ลงปฏิทินผู้พัฒนาและคุณ Suchada ให้รันซ้ำก่อนหมดอายุ

## 5. ปิดของบนโน้ตบุ๊ก
1. ปิดหน้าต่าง PowerShell ของ n8n และ cloudflared (หรือ `Ctrl+C`)
2. ส่ง `สรุป` ใน LINE อีกครั้ง ต้องยังตอบ (แปลว่าตอบจาก Cloud แล้ว)
3. งานร่างที่ค้างอยู่บนโน้ตบุ๊ก (ข้อความที่ CEO ส่งแต่ยังไม่ได้เลือกคน/วัน) จะไม่ย้ายมา ให้ CEO ส่งใหม่
4. **เก็บไฟล์ `.env` บนโน้ตบุ๊ก:** ถ้าเป็นเครื่องยืม ให้ลบ `.env` และถอนการติดตั้ง n8n หลังทดสอบ Cloud ผ่านครบแล้ว และพิจารณาออก Secret ใหม่ทั้งหมด (ใส่ค่าใหม่ในโหนด Settings)

## 6. ทดสอบหลังย้าย
ทำตาราง "ทดสอบก่อนให้ CEO ใช้" ใน [`n8n/README.md`](../../n8n/README.md) ซ้ำอย่างน้อยข้อเหล่านี้

| # | ทำ | ผลที่ต้องได้ |
|---|---|---|
| C1 | ส่ง `สรุป` | ได้สรุปภายใน 10 วินาที |
| C2 | สั่งงาน 1 งานจนได้เลข T-xx | งานขึ้นใน List `Tickets` พนักงานได้แจ้งเตือน Teams |
| C3 | พนักงานกด "ถาม CEO" ในแอป | CEO ได้ LINE ภายใน 1–2 นาที (SharePoint webhook ใช้ได้) |
| C4 | ปิดโน้ตบุ๊ก แล้วทำ C1 | ยังตอบ |
| C5 | รอวันทำการถัดไป 07:00 | ได้สรุปเช้าตรงเวลา (เขตเวลาถูก) |
| C6 | เปิดหน้า Executions | ไม่มีข้อความของ CEO ค้างใน Execution ที่สำเร็จ |

## 7. อัปเดตบอทเมื่อมีโค้ดใหม่ (ไม่ต้องกรอกค่าลับใหม่)
ใช้ไฟล์ [`n8n/ceo-line-bot-update.json`](../../n8n/ceo-line-bot-update.json) ซึ่งไม่มีโหนด Settings
1. เปิด Workflow `CEO LINE Bot`
2. โหนด Settings กับกล่องสีเหลืองอยู่แถวบนสุด โหนดอื่นอยู่ด้านล่าง ให้**กดเมาส์ค้างที่พื้นที่ว่างใต้กล่องสีเหลือง แล้วลากกรอบคลุมเฉพาะโหนดด้านล่างทั้งหมด** → กด **Delete**
3. ต้องเหลือแค่โหนด Settings กับกล่องสีเหลือง (ถ้าเผลอลบไป กด **Ctrl+Z**)
4. เปิดไฟล์ `ceo-line-bot-update.json` ด้วย Notepad → **Ctrl+A** → **Ctrl+C** → คลิกพื้นที่ว่างใน n8n → **Ctrl+V**
5. ตรวจว่าชื่อโหนดไม่มีเลขต่อท้าย (เช่น `LINE Webhook1`) ถ้ามี แปลว่ายังลบของเดิมไม่หมด ให้ลบตัวที่มีเลขต่อท้ายแล้ววางใหม่
6. **Publish** แล้วส่ง `สรุป` ทดสอบ
7. URL ของ Webhook ไม่เปลี่ยน (Path เดิม) ไม่ต้องแก้ LINE หรือ SharePoint

**ห้าม** Import ไฟล์เต็ม `ceo-line-bot.json` ทับ เพราะจะได้โหนด Settings ว่างอันใหม่ (ชื่อ `Settings1`) และบอทจะสับสน ถ้าเผลอทำ ให้ลบ `Settings1` ทิ้ง

## 8. โควตาและค่าใช้จ่าย
- Starter: ประมาณ €20–24/เดือน (จ่ายรายปีถูกกว่า) ได้ **2,500 Executions/เดือน** ⚠️ ตรวจราคาและเงื่อนไขล่าสุดที่ https://n8n.io/pricing ก่อนจ่าย
- **นับ 1 Execution ต่อการเรียก 1 ครั้ง:** ทุกข้อความหรือการแตะปุ่มของ CEO, ทุกครั้งที่ SharePoint แจ้งว่า `TicketHistory` เปลี่ยน, สรุปเช้า และสรุปวันศุกร์ (การกด Execute ทดสอบในหน้าแก้ไขไม่นับ)
- ประมาณการคร่าว ๆ:
  - CEO สั่งงาน 1 งาน ≈ 3–4 ครั้ง (ข้อความ + เลือกคน + เลือกวัน)
  - พนักงานอัปเดต 1 งาน ≈ 3–6 ครั้ง
  - ถ้า CEO สั่ง **10 งาน/วัน** จะใช้ประมาณ 100–150 ครั้ง/วันทำการ ≈ **2,200–3,300/เดือน** ใกล้หรือเกินโควตา
- **ใช้ช่วง Trial วัดของจริง:** ทดลองกับ CEO ระหว่าง Trial แล้วดูตัวเลขใน Admin panel → **Usage** ครบ 1 สัปดาห์
  - คูณ 4.5 = ยอดต่อเดือน
  - ต่ำกว่า 2,000 → ซื้อ Starter
  - สูงกว่า → ซื้อ Pro (ได้ 10,000 ครั้งและมี Variables)
- ⚠️ ถ้าใช้ครบโควตากลางเดือน บอทอาจหยุดตอบจนขึ้นรอบใหม่หรืออัปเกรด ตรวจเงื่อนไขในหน้า Pricing และตั้งให้ผู้พัฒนาได้อีเมลเตือนการใช้งาน
- **ก่อน Trial หมด 3 วัน** เลือกแพ็กเกจและใส่**บัตรบริษัท** มิฉะนั้น Instance จะถูกระงับและบอทเงียบ

## 9. ความเป็นส่วนตัวของข้อมูล
- ข้อความของ CEO ผ่านเซิร์ฟเวอร์ n8n Cloud (ผู้ให้บริการในยุโรป) ระหว่างประมวลผล
- Execution ที่สำเร็จไม่ถูกเก็บ ส่วน Execution ที่ **Error** ถูกเก็บพร้อมข้อความเพื่อใช้แก้ปัญหา ให้ลบ Execution ที่ Error ทิ้งเมื่อแก้เสร็จ
- งานร่างที่ CEO ยังเลือกคน/วันไม่เสร็จ เก็บใน Workflow ชั่วคราว และหมดอายุเองใน 30 นาที (รูปที่ส่งก่อนข้อความ 10 นาที)
- ข้อมูลงานจริงทั้งหมดยังอยู่ใน SharePoint ของบริษัทเหมือนเดิม
