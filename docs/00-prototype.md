# ต้นแบบ 1 วัน และเกณฑ์ไป/ไม่ไป

เป้าหมาย: พิสูจน์ว่า License และนโยบายของ Tenant ปัจจุบันรองรับแผนนี้จริง **ก่อน** ลงทุนสร้างเต็มรูปแบบ
ใช้บัญชีทดสอบ 2 บัญชี: บัญชีเจ้าของ (คุณ) และบัญชีพนักงานธรรมดา 1 บัญชีที่ไม่ใช่ Admin

## ขั้นตอน
| # | ทำอะไร | ผ่านเมื่อ |
|---|---|---|
| 1 | สร้าง Site `CEO-Tickets` แบบ **Communication site → Blank** ภาษา English (ห้ามใช้ Team site แบบ Standard team เพราะผูก Microsoft 365 Group ซึ่งเพิ่มสมาชิกได้จาก Outlook/Teams) ผู้ใช้สร้าง Site เองได้ (ตรวจแล้ว) | ใน Advanced permissions: Members/Visitors ว่าง ไม่มีกลุ่ม Everyone และ Owners มีแค่ผู้สร้าง |
| 2 | สร้าง List `Tickets` ตาม [01-data-model.md](01-data-model.md) อย่างน้อย 5 คอลัมน์ (Title, Assignee, DueDate, Status, IsOpen) | สร้างได้ |
| 3 | สร้าง Canvas App 1 หน้า แสดงรายการจาก `Tickets` | เปิดได้ ไม่มีไอคอน Premium ที่ตัว Connector |
| 4 | สร้าง Flow ตัวกระตุ้น **Power Apps (V2)** ที่สร้างรายการ แล้ว **Stop sharing an item** และ **Grant access to an item** ให้ผู้รับผิดชอบ | Flow รันสำเร็จ และไม่มีคำเตือนเรื่อง Premium |
| 5 | ใน Flow เดียวกัน เพิ่มการแจ้งเตือนแบบ Push ไปยังผู้รับผิดชอบ (ลอง `Send a push notification (V2)` ของ Power Apps Notification ⚠️ หากใช้ไม่ได้ ให้ลองข้อความ Teams หรืออีเมลเป็นแผนสำรอง) | มือถือทดสอบได้รับแจ้งเตือนภายในไม่กี่วินาทีหลังกดปุ่มในแอป |
| 6 | ใช้บัญชีพนักงานทดสอบเปิดแอป | เห็นเฉพาะ Ticket ที่ตัวเองเป็นผู้รับผิดชอบ |
| 7 | ใช้บัญชีพนักงานทดสอบเปิด URL ของ List ใน SharePoint ตรง ๆ | **เข้าไม่ได้หรือเห็นเฉพาะใบของตัวเอง** (ถ้าเห็นทุกใบ แปลว่าสิทธิ์รั่ว หยุดแล้วแก้ก่อน) |
| 8 | ในแอป เพิ่ม Connector **Office 365 Outlook** แล้วอ่านนัดหมายของวันนี้ และสร้างนัด Private 1 รายการด้วยบัญชี CEO ทดสอบ | อ่านและสร้างได้ และเห็นใน Outlook |
| 9 | ติดตั้งแอป Power Apps บน iPhone และ Android อย่างละ 1 เครื่อง ตั้งทางลัดบนหน้าจอโฮม | เปิดจากทางลัดได้ และรับแจ้งเตือนได้ทั้งสองระบบ |
| 10 | ลองสร้างแอปและ Flow ภายใน **Solution** ⚠️ เพื่อ Export เก็บใน Git ได้ | Export เป็น `.zip` ได้ |
| 11 | **(สำคัญ)** หลัง Flow ตั้งสิทธิ์เฉพาะรายการแล้ว ให้ n8n อ่านและแก้รายการนั้นผ่าน Graph (ส่ง "สรุป" แล้วกดปิดงานจาก LINE) ⚠️ ยังไม่แน่ใจว่าสิทธิ์ `Sites.Selected` ของแอปยังเข้าถึงรายการที่ตัดการสืบทอดสิทธิ์ได้ | สรุปนับงานครบ และปิดงานจาก LINE ได้ ถ้าไม่ได้ ต้องให้ Flow ให้สิทธิ์แอปเพิ่มในแต่ละรายการ |
| 12 | Graph เขียน `DueDate` เป็น `YYYY-MM-DDT00:00:00Z` | วันที่ใน SharePoint ตรงกับวันที่ CEO เลือก (ไม่เลื่อน 1 วัน) |

## เกณฑ์ตัดสิน
- **ไปต่อ** ถ้าข้อ 3–9 ผ่านทั้งหมด
- **ปรับแผน** ถ้าข้อ 5 ล้มเหลว แต่ข้ออื่นผ่าน ใช้ Teams หรืออีเมลเป็นช่องทางแจ้งเตือนหลัก
- **หยุดและทบทวน** ถ้าข้อ 4 หรือ 7 ล้มเหลว เพราะกระทบความลับของข้อมูล ซึ่งกลับไปพิจารณาแอป Native + Backend ตามที่เคยคุยกัน
